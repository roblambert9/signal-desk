# Prospect

## ICP (this book)

Score 0–3. Pursue only 2+.

| Signal | +1 if |
|---|---|
| Runs agents in production (Codex, Cursor, n8n, Claude Code) | they say so, or a public SKILL.md / MCP |
| Sells implementation, not chat wrappers | agency, SI, Shopify/Salesforce shop |
| Has a repo they want distilled | they paste a github.com URL |
| Will pay a person this week | asks for a price, not a partnership |

Kill immediately: build my SaaS for equity, email my list, make it viral.

## Discovery (two questions, then price)

1. What has to ship this week?
2. Who pays?

Then quote. If there is no repo URL, sku is ep01, not Foundry.

## Targeting

Pick one named account. One person. One channel.

Order of channels (do not skip to a list):

1. Reply on a thread they already started (HN comment, GitHub issue, X reply)
2. GitHub issue #1 format if they have a repo
3. One email to a published address
4. Booking only after they ask

Body max 90 words. One ask. One price. One link.

## Sequence (3 touches, then die)

1. Proof
2. Price — one SKU
3. Walk

Do not add a fourth touch.

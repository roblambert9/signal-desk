# Negotiate

Run `scripts/quote.py` before you write a sentence. The verdict is the reply type.

## First ask

Always list price. Never open at floor.

## Concession ladder (private SKUs only)

1. Hold list. Add a written deliverable.
2. Trade to floor. Name the trade from floors.json.
3. Walk. Offer ep01 or playbook.

One concession per reply.

## Close

Pay path + delivery path in the same message. Quote dies in 24h. Re-quote at list.
